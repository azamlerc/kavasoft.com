Developer Documentation

This page allows you to access documentation for the classes you'll need to interact with when writing player plug-ins. Each player plug-in's principal class is a subclass of ICComputerPlayer. To define the personality of your player, you simply override eight methods defined in ICPlayer.

For complete instructions, please visit the iConquer Developer page.
