NSBundle (ICBundle)


Declared In:
ICBundle.h


Category Description

Some convenience methods useful for iConquer plug-in bundles.

Method Types

- bundleName
- bundleFamilyName
- bundleChildName
- bundleVersion
- bundleFamilyIdentifier
- pluginType
- isInSameFamilyAs:
- myObjectForInfoDictionaryKey:
- compareBundleName:

Instance Methods

bundleChildName

- (NSString *)bundleChildName

Returns the part of the name in parentheses. For example, if the name is "iConquer World (Medium)", returns "Medium".

bundleFamilyIdentifier

- (NSString *)bundleFamilyIdentifier

If the plug-in is part of a family, returns the identifier without the last segment. For example, if the identifier is "com.kavasoft.iConquer.maps.world.medium", returns "com.kavasoft.iConquer.maps.world".

bundleFamilyName

- (NSString *)bundleFamilyName

Returns the part of the name not in parentheses. For example, if the name is "iConquer World (Medium)", returns "iConquer World".

bundleName

- (NSString *)bundleName

Returns the value of CFBundleName.

bundleVersion

- (NSString *)bundleVersion

Returns the value of CFBundleVersion.

compareBundleName:

- (NSComparisonResult)compareBundleName:(NSBundle *)value

Performs a case insensitive comparison of the bundle names.

isInSameFamilyAs:

- (BOOL)isInSameFamilyAs:(NSBundle *)bundle

Returns whether self and bundle have the same ICFamilyIdentifier value.

myObjectForInfoDictionaryKey:

- (id)myObjectForInfoDictionaryKey:(NSString *)key

Returns the localized info dictionary value for key. This method wraps objectForInfoDictionaryKey: for compatibility with 10.1. On 10.2 or later, simply calls objectForInfoDictionaryKey:. On earlier versions, uses a custom implementation that does the same thing.

pluginType

- (NSString *)pluginType

Returns the value of ICPluginType.
