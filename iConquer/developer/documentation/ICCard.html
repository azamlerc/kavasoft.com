ICCard is a simple class that represents a card.

Method Types

- suit

Instance Methods

country

- (ICCountry *)country

The card's country. This value is nil for wild cards.

suit

- (int)suit

The card's suit, which can be 0, 1, or 2 for regular cards or -1 for wild cards.
