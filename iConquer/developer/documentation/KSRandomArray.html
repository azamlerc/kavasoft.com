NSArray (KSRandomArray)


Declared In:
KSRandomArray.h


Category Description

A few convenience methods for NSArray.

Method Types

- randomObject
- randomObjectTowardsEnd
- containsObjects:

Instance Methods

containsObjects:

- (BOOL)containsObjects:(NSArray *)otherArray

Retruns YES if the array contains all elements in otherArray.

randomObject

- (id)randomObject

Returns a random object in the array.

randomObjectTowardsEnd

- (id)randomObjectTowardsEnd

Returns a somewhat random object in the array, tending towards the end. About a quarter of the time the object will be the last one, half the time the object will be in the last 10%, and occasionally the object will be in the first half.
